# 🦖 동물 vs 동물 — ARBS 샌드박스 배틀

동물·공룡·괴수를 **3D 전장에 직접 배치하고**, 무기까지 달아 싸우게 하는
**Animal Revolt Battle Simulator(ARBS)** 스타일 샌드박스 오토배틀러.

- **라이브**: https://coconawe-dev.github.io/animal-vs-animal/
- **저장소**: https://github.com/coconawe-dev/animal-vs-animal
- **거대한 3× 전장** (직경 약 99m) · **최대 100마리** 난전 (50 vs 50, 80 vs 10 모두 가능)
- **🎮 유닛 직접 조종** — 배틀 중 아무 유닛이나 골라 3인칭 시점으로 직접 몰 수 있습니다 (WASD/방향키 · 조이스틱 · 공격 · 스킬)
- **💣 전장 아이템 5종** — 지뢰 · 자동 포탑 · 테슬라 코일 · 치유 토템 · 가시 바리케이드 (제자리에서 스스로 싸우는 구조물)
- 외부 모델·이미지 파일 없음: 유닛 38종(샌즈 1·2·3페이즈 포함) + 아이템 5종 3D 모델·전장·무기·이펙트·효과음까지 전부 코드로 절차 생성
- 설치 없이 브라우저에서 바로 실행 (Three.js 0.169 로컬 벤더링)

## 🕹️ 플레이 방법 (ARBS 방식)

1. **팀 선택** — 좌측 상단에서 `🔵 블루` / `🔴 레드`를 고릅니다. 전장 중앙에 진영 구분선이 있습니다. (파티에서는 내 진영 하나만 보입니다.)
2. **유닛 선택** — 아래 유닛 바에서 동물·공룡·괴수, 또는 `💣 아이템` 탭에서 전장 장치를 탭합니다.
3. **땅을 탭** — 3D 전장의 원하는 지점을 탭하면 **그 자리에 정확히 소환**됩니다. (블루는 서쪽, 레드는 동쪽 / `자유 배치`를 켜면 중앙선을 넘어도 됩니다.)
4. **무기 장착** — `🔫 개틀링` · `🚀 로켓` · `⚡ 레이저` · `🛡️ 스파이크 방패`를 고른 뒤 배치하면 등에 실제로 장착되어 발사합니다.
5. **⚔️ 배틀 시작** — 유닛들이 알아서 싸웁니다. 끝나면 MVP와 승패가 표시됩니다.
6. **🎮 직접 조종** — 배틀 중 살아 있는 유닛을 탭하면 나오는 **추적 바**에서 `🎮 직접 조종`을 누르면 그 유닛을 직접 몰 수 있습니다. (자세한 조작은 아래 표)

### 배치 도구

| 도구 | 설명 |
| --- | --- |
| **×1 · ×3 · ×5 · ×10** | 한 번 탭으로 1·3·5·10마리를 뭉쳐 소환 (떼 지어 몰려오는 난전용) |
| **🧽 지우개** | 탭한 유닛을 제거 |
| **↩️ 되돌리기** | 마지막 배치를 취소 (최대 40단계) |
| **⇄ 대칭** | 현재 팀 배치를 반대편에 좌우 대칭으로 복사 |
| **🗑️ 비우기** | 현재 팀을 전부 비움 |
| **자유 배치** | 중앙 구분선을 무시하고 전장 어디든 배치 |
| **최대 인원** | 전장 100마리까지 (한 팀 한도 없음 — 80 vs 10, 50 vs 50 모두 가능) |

### 바로 시작하는 프리셋

`🦖 티라노 vs 랩터 12마리` · `🐘🚀 로켓 코끼리 vs 사자 무리` · `🦖 공룡 대전` · `👹 거대 보스 레이드` · `🧟 신규 유닛 쇼케이스` · `🐔⚔️💀 강하닭 vs 샌즈` · `💀⚔️🐔 라스트 브레스 3페이즈 vs 강하닭` · `🦣🐍🦍🦸 신규 4종 쇼케이스` · `💣🗼⚡ 전장 아이템 쇼케이스` · `💥 100마리 대난전` · `1:1 라이벌` · `3v3 밸런스` · `정글 vs 사바나`
→ 하단 `🎲 프리셋` 버튼에서 한 번에 적용. (전장 3종도 같은 패널에서 선택)

### 관전 도구

| 조작 | 동작 |
| --- | --- |
| 드래그 / 두 손가락(휠) | 카메라 회전 · 확대/축소 |

| 2× | 배속 |

### 🎮 직접 조종 조작

배틀 중 유닛을 탭 → **🎮 직접 조종**. 카메라가 그 유닛의 **등 뒤·약간 위**에서 부드럽게 따라가는 3인칭 시점이 됩니다.

| 조작 | 동작 |
| --- | --- |
| **WASD / 방향키** | 이동 (카메라 기준 전후좌우) |
| **왼쪽 아래 조이스틱** (터치) | 드래그한 방향으로 이동, 손을 떼면 정지 |
| **⚔️ 공격** · `Space` · 좌클릭 | 바라보는 방향/가까운 적에게 기본 공격 (쿨타임 표시) |
| **✨ 스킬** · `E` · `Shift` | 그 유닛의 고유 필살기 즉시 발동 (쿨타임 체크, 남은 초 표시) |
| 화면 드래그 | 시야 회전 (그 방향으로 유닛도 돌아봄) |
| **❌ 조종 해제** · `Esc` | AI 자동 전투 + 자유 관전 시점으로 복귀 |

- 조종 중인 유닛은 **AI 자동 이동·자동 공격을 멈추고** 입력만 따릅니다.
- 조종 중인 유닛이 쓰러지면 **자동으로 조종이 해제**되고 알림이 뜹니다.
- 파티에서도 내 진영 유닛을 조종할 수 있고, 입력은 방장 시뮬레이션에 전달되어 다른 참가자 화면에도 그대로 동기화됩니다. (아이템은 조종 불가)

**강하닭**은 우리가 만든 RPG 게임의 최종 보스로, 크림·황금 깃털에 붉은 벼슬·육수,

**샌즈**는 언더테일의 그 샌즈로, 파란 후드 재킷·흰 셔츠·흰 줄무늬 반바지·분홍 슬리퍼에
빛나는 시안 왼쪽 눈을 가졌습니다. 가스터 블래스터(해골이 쏘는 굵은 관통 빔), 뼈 발사(8연사),
뼈 가시(발밑에서 솟는 광역), 그리고 근접 위협 시 잔상을 남기는 순간이동을 씁니다.

| 2페이즈 | 25 | 가슴의 붉은 대각선 베인 상처 · 입가의 피 · 왼손의 뼈다귀. 기술 구성은 1페이즈와 같지만 ATK 82로 훨씬 무겁습니다 |
| 3페이즈 | 50 | 깨져 금이 간 두개골 · 새까만 빈 눈 · 등 뒤의 반투명 가스터 그림자 + 푸른 오라. **체력 2100(강하닭과 동급)**, ATK 115, 회피 30% |

3페이즈는 2페이즈의 네 기술에 두 가지를 더해 다섯 기술을 돌려 씁니다.

- **🖕 불미스러운 공격** — 가운뎃손가락을 치켜든 픽셀 손들이 사방에 떠올라 적을 조준해 터지고,
  화면에 `🖕 불미스러운 공격!` 글자가 크게 뜹니다(큰 피해 + 충격 + 둔화)

**히드라는 목이 셋으로 갈라진 다두룡**으로 세 머리가 동시에 초록·보라 맹독을 뿜고,

## ⚔️ 전투 시스템

- **AI**: 가까운 적을 노리되 아군이 붙은 적은 피해 옆으로 돌아 들어가고, 원거리는 거리를 유지하며 카이팅합니다.
- **종족별 공격 모션**: 티라노·사자·악어·뱀·하이에나 등은 **입을 크게 벌렸다 물어뜯고**, 코뿔소·트리케·멧돼지·코끼리는 **머리(뿔·엄니·코)를 숙였다 위로 받아올리며**, 고릴라·타이탄·곰은 **양팔(앞발)을 들어 내리치고**, 독수리·와이번은 **날개를 편 채 급강하해 부리와 발톱으로 낚아챕니다**. 좀비는 **뻗은 두 팔로 할퀴고**, 스켈레톤은 **뼈칼을 사선으로 내리치며**, **디-렉스는 물기와 주먹 휘두르기를 번갈아** 쓰고 필살기로 둘을 연계합니다.
- **물리감**: 방어력·회피·기절·둔화·출혈·화상·공속 버프·넉백 저항이 모두 실제 계산에 들어갑니다. 무거운 일격은 경량 유닛을 띄워 회전시킵니다.
- **판정**: 마지막 한 진영만 남으면 즉시 종료, 240초 초과 시 남은 HP 비율 1위 판정. (2~4팀 모두 동일)
- **재현성**: 시드 고정 시뮬레이션으로 같은 결과가 나옵니다.
