# 🦖 동물 vs 동물 — ARBS 샌드박스 배틀

동물·공룡·괴수를 **3D 전장에 직접 배치하고**, 무기까지 달아 싸우게 하는
**Animal Revolt Battle Simulator(ARBS)** 스타일 샌드박스 오토배틀러.

- **라이브**: https://coconawe-dev.github.io/animal-vs-animal/
- **저장소**: https://github.com/coconawe-dev/animal-vs-animal
- 외부 모델·이미지 파일 없음: 유닛 18종 3D 모델·전장·무기·이펙트·효과음까지 전부 코드로 절차 생성
- 설치 없이 브라우저에서 바로 실행 (Three.js 0.169 로컬 벤더링)

---

## 🕹️ 플레이 방법 (ARBS 방식)

1. **팀 선택** — 좌측 상단에서 `🔵 블루` / `🔴 레드`를 고릅니다. 전장 중앙에 진영 구분선이 있습니다.
2. **유닛 선택** — 아래 유닛 바에서 동물·공룡·괴수를 탭합니다.
3. **땅을 탭** — 3D 전장의 원하는 지점을 탭하면 **그 자리에 정확히 소환**됩니다. (블루는 서쪽, 레드는 동쪽 / `자유 배치`를 켜면 중앙선을 넘어도 됩니다.)
4. **무기 장착** — `🔫 개틀링` · `🚀 로켓` · `⚡ 레이저` · `🛡️ 스파이크 방패`를 고른 뒤 배치하면 등에 실제로 장착되어 발사합니다.
5. **⚔️ 배틀 시작** — 유닛들이 알아서 싸웁니다. 끝나면 MVP와 승패가 표시됩니다.

### 배치 도구

| 도구 | 설명 |
| --- | --- |
| **×1 · ×3 · ×5** | 한 번 탭으로 1·3·5마리를 뭉쳐 소환 (떼 지어 몰려오는 난전용) |
| **🧽 지우개** | 탭한 유닛을 제거 |
| **↩️ 되돌리기** | 마지막 배치를 취소 (최대 40단계) |
| **⇄ 대칭** | 현재 팀 배치를 반대편에 좌우 대칭으로 복사 |
| **🗑️ 비우기** | 현재 팀을 전부 비움 |
| **자유 배치** | 중앙 구분선을 무시하고 전장 어디든 배치 |
| **최대 인원** | 한 팀 30마리 · 전장 60마리까지 |

## ⚔️ 전투 시스템

- **AI**: 가까운 적을 노리되 아군이 붙은 적은 피해 옆으로 돌아 들어가고, 원거리는 거리를 유지하며 카이팅합니다.
- **물리감**: 방어력·회피·기절·둔화·출혈·화상·공속 버프·넉백 저항이 모두 실제 계산에 들어갑니다. 무거운 일격은 경량 유닛을 띄워 회전시킵니다.
- **판정**: 한쪽 전멸 시 즉시 종료, 180초 초과 시 남은 HP 비율로 판정.
- **재현성**: 시드 고정 시뮬레이션으로 같은 결과가 나옵니다.

## ⚔️ 챌린지 (6단계)

`⚔️ 챌린지` 탭에서 이어서 도전합니다. 단계마다 **레드 군단이 미리 배치**되어 있고,
블루는 **예산** 안에서 유닛을 사서 배치합니다. 이기면 다음 단계가 열리고 진행도는 저장됩니다.

| 단계 | 상대 | 예산 |
| --- | --- | --- |
| 1. 랩터의 습격 | 랩터 5 | 10 |
| 2. 늑대 무리 | 늑대 6 + 멧돼지 2 | 14 |
| 3. 티라노 사냥 | 티라노 + 트리케 + 랩터 3 | 20 |
| 4. 무장한 맹수 | 개틀링 곰 2 + 로켓 사자 2 + 방패 트리케 | 24 |
| 5. 뿔의 방벽 | 트리케 3 + 멧돼지 6 | 28 |
| 6. 타이탄 최종전 | 타이탄 + 와이번 2 + 트리케 + 레이저 사자 | 30 |

## 🧪 테스트

```bash
npm test            # node tests/smoke.mjs — 데이터·배치·시뮬·무기·3D 2,000+ 항목
node tests/fuzz.mjs # 무작위 600판 + 60마리 5판 (NaN·이탈·미종료 검사)
node tests/ui.mjs   # 배치 도구/챌린지/HUD 배선 (npm i --no-save jsdom 필요)
```

`tests/smoke.mjs`는 DOM·WebGL 없이 다음을 검사합니다.

- 데이터: 18종 능력치·스킬·무기 5종·프리셋 7종·챌린지 6단계·전장 3종
- 배치: ×1/×3/×5 클러스터, 진영 제한, 자유 배치, 인원 제한, 지우개, 대칭 복사, 저장값 정리
- 시뮬레이션: 1:1 전 조합 324판(무기 로테이션), 프리셋 × 전장, 60마리 난전, 챌린지 6단계
- 무기: 개틀링 연사, 로켓 폭발, 레이저 관통, 방패 정면 감소·밀치기
- 3D: 18종 모델 메시·크기·발 높이, 무기 장착, 180프레임 애니메이션·사망 연출의 NaN 여부

```

src/sim.js            전투 시뮬레이션 (순수 로직, THREE/DOM 비의존)
src/models.js         유닛 3D 모델 + 무기 장착 + 절차적 애니메이션 리그
src/scene.js          렌더러 · 조명 · 진영 구분선 · 배치 고스트 · 카메라
src/effects.js        피해 숫자 · 탄환 · 로켓 폭발 · 레이저 빔 · 화염
src/ui.js             배치/챌린지/전투 UI
src/audio.js          WebAudio 합성 효과음 (총성 · 로켓 · 레이저 포함)
src/main.js           게임 루프 · 3D 탭 배치 · 이벤트 연결
vendor/three.module.js  Three.js r169 (로컬)
tests/smoke.mjs       오프라인 검증
tests/fuzz.mjs        무작위 퍼즈
tests/ui.mjs          jsdom UI 배선 검사
```

## 📱 기기 대응

- iPhone 390×844 세로 · iPad 세로/가로 · 데스크톱에서 레이아웃이 바뀝니다.
  (좁은 화면은 하단 도크, 가로 태블릿은 왼쪽 도구 패널 + 넓은 유닛 바)
- 3D 전장이 항상 화면 중앙에 보이도록 카메라 프레이밍을 자동 보정합니다.
- 세이프 에어리어 패딩, 더블탭 확대·스크롤 차단, 터치 타깃 44px 이상.
- 유닛이 18마리를 넘으면 저해상도 모델·그림자 축소로 자동 경량화하고,
  3초간 FPS가 34 미만이면 해상도를 낮춥니다.
