# 🐾 동물 vs 동물 — 3D AI 배틀

12종의 동물을 골라 두 팀을 만들면, 동물들이 **스스로 적을 찾아 싸우는** Three.js 3D 오토배틀러.
사자의 포효, 호랑이의 급습 도약, 코끼리의 돌진까지 — 각자의 필살기가 쿨타임마다 자동으로 터진다.

- **라이브**: https://coconawe-dev.github.io/animal-vs-animal/
- **저장소**: https://github.com/coconawe-dev/animal-vs-animal
- 외부 모델·이미지 파일 없음: 동물 3D 모델·전장·이펙트·효과음까지 전부 코드로 절차 생성
- 설치 없이 브라우저에서 바로 실행 (Three.js 0.169 로컬 벤더링, CDN 의존 없음)

**패시브**: 늑대는 곁에 아군이 많을수록 빨라지고, 악어·코뿔소·코끼리는 넉백을 덜 받으며,
여우·치타는 기본 회피를 갖는다. 늑대·멧돼지는 평타에도 출혈을 남긴다.

### AI는 이렇게 싸운다
- 가장 가까운 적을 기본으로 노리되, **아군이 이미 붙은 적은 피해 옆으로 돌아 들어간다**(측면 분산).
- 체력이 적은 적을 마무리하려 하고, 원거리(독수리)는 사거리를 유지하며 **카이팅**한다.
- 필살기는 쿨타임 + 상황 조건(사거리·적 밀집·체력)을 만족할 때 자동 발동한다.
- 넉백·기절·둔화·출혈·방어력·회피·공속 버프가 모두 실제 전투 계산에 들어간다.

## 🧪 테스트

```bash
npm test          # 또는 node tests/smoke.mjs
npm run balance   # 1:1 승률표
```

`tests/smoke.mjs`는 DOM·WebGL 없이 1,000개 이상의 항목을 검사한다.

- 데이터: 12종 능력치·스킬·색상·프리셋·장애물 배치 유효성
- 시뮬레이션: 1:1 전 조합(144판)과 프리셋 × 전장 전부가 승패 판정까지 종료, NaN 없음, 스킬 12종 전부 발동
- 규칙: 방어력/방어 무시/회피 확률, 전멸 즉시 종료, 시간 초과 시 HP 비율 판정, 시드 고정 시 결과 동일
- 3D: 12종 모델의 메시 수·크기·발 높이, 180프레임 애니메이션과 사망 연출의 NaN 여부

## 🛠 구조

```
index.html            화면 골격 (편성 패널 · HUD · 결과창)
styles.css            다크 아레나 UI, 폰/태블릿/데스크톱 반응형
src/config.js         동물 12종 데이터 · 전장 · 프리셋 · 밸런스 상수
src/sim.js            전투 시뮬레이션 (THREE/DOM 비의존 순수 로직)
src/models.js         동물 3D 모델 빌더 + 절차적 애니메이션 리그
src/scene.js          렌더러 · 조명 · 전장 생성 · 카메라
src/effects.js        피해 숫자 · 파편 · 충격파 · 참격
src/ui.js             편성/전투 UI
src/audio.js          WebAudio 합성 효과음
src/main.js           게임 루프 · 이벤트 연결
vendor/three.module.js  Three.js r169 (로컬)
tests/smoke.mjs       오프라인 검증
```

### 로컬 실행
```bash
npm start           # python3 -m http.server 8080
# 브라우저에서 http://localhost:8080
```
(ES 모듈이라 `file://`로는 열리지 않습니다.)
